Two lines that explain a toaster to a 10-year-old through a concrete, surprising analogy — a tiny sunbed for bread — and then honestly say what that analogy maps and what it leaves out (the pop).

## Run it

```sh
python3 main.py
```

The program writes the two-line entry to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`).
